# Linux File Permissions and Access Control

## Project Overview

This project was completed as part of the **Google Cybersecurity Certificate training**.

The exercise involved reviewing and managing file and directory permissions in a Linux environment, simulating the responsibilities of a cybersecurity professional working with an organisation's research team.

The primary objective was to identify unauthorized access, modify permissions, and ensure that sensitive files and directories were accessible only to authorized users.

## Project Objectives

- Examine existing file and directory permissions.
- Identify unauthorized write access.
- Understand and interpret Linux permission strings.
- Modify file permissions using `chmod`.
- Manage hidden files and directories.
- Apply the principle of least privilege to access control.

## Tools and Commands Used

| Command | Purpose |
|---|---|
| `ls -la` | Display all files, including hidden files, with detailed permission information. |
| `ls -l` | Display detailed file and directory information. |
| `ls -ld` | Display permissions of a directory itself. |
| `chmod` | Modify file and directory permissions. |
| `pwd` | Display the current working directory. |
| `cd` | Navigate between directories. |

## Key Cybersecurity Concepts

**1. Linux File Permissions**

Understanding how Linux controls access to files and directories through read, write, and execute permissions.

**2. Access Control**

Reviewing existing permissions to identify and restrict unauthorized access to sensitive resources.

**3. Principle of Least Privilege**

Ensuring users have only the permissions necessary to perform their assigned responsibilities.

**4. Hidden Files and Directories**

Identifying hidden files and examining their permissions to ensure appropriate access restrictions.

## Skills Demonstrated

- Linux command-line operations.
- File and directory permission management.
- Access control and permission auditing.
- Identification of excessive permissions.
- Application of the principle of least privilege.
- Basic Linux security administration.

## Learning Outcomes

This exercise provided practical exposure to Linux file permission management and demonstrated how access controls help protect sensitive organisational information.

It strengthened my understanding of how cybersecurity professionals use Linux commands to review permissions, identify potential security weaknesses, and enforce appropriate access restrictions.
